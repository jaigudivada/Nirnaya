# Nirnaya — Decision Wheel

**A Jai Verse Product** — *by Jai Gudivada*

**Make Decisions with Elegance**

## Overview

Nirnaya is an interactive decision wheel that brings clarity to your choices. Whether you're picking a restaurant, deciding what to watch, or making any tough decision, Nirnaya makes it fun and visually stunning. Spin the wheel and let fate decide with style.

## Features

- **Interactive Wheel Spinning** - Smooth, physics-based spin animations
- **8 Unique Wheel Designs** - Classic, Flower, Fan, Star, Galaxy, Neon, Cyber, Rainbow
- **Customizable Options** - Add, edit, and remove your own choices
- **Beautiful Animations** - Professional, polished visual experience
- **Light & Dark Mode** - Seamless theme switching
- **Premium Preloader** - Elegant loading experience
- **Responsive Design** - Works seamlessly on desktop and mobile devices
- **Fast Performance** - Optimized loading and rendering

## Getting Started

### Prerequisites

- Modern web browser with Canvas support (Chrome, Firefox, Safari, Edge)
- JavaScript enabled
- No installation required — just open in browser!

### Installation

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start making decisions!

## Usage

- **Add Options** - Type your choices into the input field and click "Add"
- **Choose Design** - Browse 8 stunning wheel designs from the design selector
- **Spin the Wheel** - Click "Spin the Wheel" to let fate decide
- **View Result** - A modal displays your winning choice
- **Light/Dark Mode** - Toggle themes with the button in the header
- **Clear All** - Remove all options and start fresh
- **Spin Again** - Need another decision? Just spin again
- **Edit Options** - Modify your options after seeing the result

## Technology Stack

- **HTML5 Canvas** - High-performance wheel rendering
- **CSS3** - Modern styling with animations and gradients
- **Vanilla JavaScript** - Core functionality and physics engine
- **Inter & Space Grotesk Fonts** - Clean, modern typography (via Google Fonts)

- Try a different modern browser
